# NOOR Documentation Archive

This directory stores superseded project documents for historical traceability.

## Rules

- Archived documents are historical records, not current instructions.
- Every archived document must identify its current replacement, where one exists.
- Do not delete old evidence merely because a newer status document exists.
- Current status, operating instructions and approved design specifications belong in the active `docs/` index.
- Keep dated test evidence immutable where practical; append a dated correction or superseding record rather than silently rewriting historical outcomes.
